# BUCKSAW — manual

**betobullet** · 4 HP · super-oscilador estéreo

O Bucksaw tem três vozes, cada uma com sete ondas desafinadas entre si, que vão de *super saw* a
*super square*. As ondas se espalham entre as saídas L e R. Ele recria o funcionamento descrito no
manual do Acid Rain Chainsaw. O timbre é uma aproximação: a curva de detune é a do supersaw do
JP-8000.

---

## 1. Controles

| Controle | O que faz |
|---|---|
| **Encoder** | Nota raiz das três vozes. Cada passo vale **1 semitom** (LED NOTE). |
| clique no encoder | Alterna para passos de **1 cent** (LED ALT). |
| segurar 2 s | Volta a raiz para **C1** (32,7 Hz). |
| **DETUNE** | Espalha as 7 ondas de cada voz: 3 acima, 3 abaixo e 1 na raiz. No mínimo ficam em uníssono perfeito; a curva é não linear. |
| **MORPH** | Leva todas as ondas de dente de serra a quadrada. |

Com o mouse: **arrastar ou rolar** gira o encoder, e **clicar** alterna NOTE/ALT. Passar o mouse
mostra a nota, os cents e os Hz.

## 2. Jacks

| Jack | O que faz |
|---|---|
| **V/O 1, 2, 3** | 1 V/oitava de cada voz. **Uma voz só toca com cabo no seu V/O.** |
| **DTN** | CV de detune, ±5 V somados ao knob |
| **MRPH** | CV de morph, ±5 V somados ao knob |
| **FM** | FM linear em todas as vozes: ±5 V levam a frequência de 0 a 2x |
| **OUT L / OUT R** | Saídas estéreo. As 7 ondas de cada voz se espalham entre L e R. Uma saída sozinha funciona como mono. |

## 3. Começando

1. Ligue qualquer fonte de 1 V/oct (MIDI-CV, sequenciador) em **V/O 1**.
2. Ligue **OUT L** (e **OUT R**) no mixer.
3. Abra o **DETUNE** para ouvir o efeito "chainsaw".
4. Ligue **V/O 2** e **V/O 3** para tocar acordes de três notas, com até 21 ondas.

Com 0 V no V/O, a voz toca na raiz do encoder, que começa em C1, bem grave. Gire o encoder para
subir.

## 4. Menu de contexto

- **Fine tune (alt)**: o mesmo que o clique no encoder.
- **Root to C1**: volta a raiz para C1.
- **Theme**: Black ou White.
